# Security Policy

## Reporting a vulnerability

**Do not open a public issue, pull request, or discussion.** Report privately through
**Security, Report a vulnerability** on the public repository
(github.com/globalmpc/rwa-kit-js), or by email to mpc@globalmpc.tech.

Please include:

- package and version
- reproduction steps, as small as possible
- expected impact

We follow up inside the advisory. Please keep details private until a fix is released.

## Scope

Every package under `packages/`. Dependencies are out of scope; report those upstream.

## Supported versions

The latest release of each package.
